# Iris Decision Tree Classification

**Andrey Castel | MGT-661 | November 8, 2026**

A simple machine learning project using scikit-learn's Iris dataset and a Decision Tree classifier to predict flower species from four measurements.

## Results

- Accuracy: **96.67%**
- Correct Predictions: **29 of 30**

## Run the Project

Open **Iris Decision Tree Castel, Andrey.ipynb** in Jupyter Notebook or Google Colab and run all cells.
